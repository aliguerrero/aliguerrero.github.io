# ali.guerrero — portafolio

Portafolio personal de **Ali Guerrero**, ingeniero en informática (Venezuela).

Sitio: https://aliguerrero.github.io

Una sola página estática (HTML, CSS y JavaScript, sin dependencias ni proceso de build) con demos interactivas de cada proyecto y capturas de los sistemas reales.

## Desarrollo

Abre `index.html` en el navegador. Para publicar cambios, haz commit y push a `main`: GitHub Pages se actualiza solo.
